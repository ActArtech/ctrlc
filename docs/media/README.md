# Demo media

Placeholder for short demo GIF / video of CtrlC SectionPack.

## What to record

Use the **Northline** demo only (`examples/next-demo`, typically http://localhost:3040).  
**No third-party brands**, logos, or product UI.

Capture these beats (order recommended):

1. **Inspector toggle** - enable SectionPack mode (Ctrl/Cmd+Shift+P or product default) so section chips / boundaries appear  
2. **Pack describe** - open dual export and show **Natural language** (`describe`) for one section  
3. **Pack prompt** - switch to **Code as-is** (`prompt` / multi-file pack) for the same section  

Optional tail: `/dev/packs` catalog with Northline preview thumbs.
